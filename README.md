Title : Book Scraper 
What it does :A Python script that visits books.toscrape.com, collects the title and price of each book on the first page, and saves them to `books.csv`.
How to run it :  
1. Install Python from python.org
2. Install the libraries:
   pip install requests beautifulsoup4
3. Run the script:
   python scraper.py
Tool I used: Python, requests, BeautifulSoup
